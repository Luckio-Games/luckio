## 🎮 Реализованные игры

### 1. 🎾 **Ракетка (Rocket Game)**
- Crash-игра с растущим множителем
- 5 вариантов ставок: 10 / 50 / 100 / 500 / 1000 ⭐
- Множитель от 1.00x до 20.00x
- Вероятностное распределение crash point
- Кнопка "ЗАБРАТЬ" для получения выигрыша
- 3D анимация ракеты и частиц
- Screen shake при crash

### 2. 🎁 **Кейсы (Cases System)**
- **4 типа кейсов:**
  - Starter Case (100 ⭐)
  - Lucky Case (250 ⭐)
  - Epic Case (500 ⭐)
  - Diamond Case (1000 ⭐)

- **Система редкостей:**
  - Common (множитель 0.5x-1.5x)
  - Rare (множитель 1.5x-3.0x)
  - Epic (множитель 3.0x-6.0x)
  - Legendary (множитель 6.0x-12.0x)

- Анимация ленты с 60 предметами (5 секунд)
- Эффекты по редкостям (частицы, glow, shake)

### 3. 🎲 **Lucky Dice**
- Бросок кубика с 3D анимацией
- Таблица выплат:
  - 1️⃣ → x0 (проигрыш)
  - 2️⃣ → x0.5
  - 3️⃣ → x1 (возврат)
  - 4️⃣ → x2
  - 5️⃣ → x3
  - 6️⃣ → x5 (джекпот!)
- CSS 3D кубик с 6 гранями
- Анимация вращения 2.5 секунды
